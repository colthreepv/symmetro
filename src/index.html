A closer look at what happens here +

Encrypt & decrypt

AES-256-GCM with a fresh random salt and IV for each message. Passwords are derived with PBKDF2-SHA256 at 100,000 iterations. Existing Symmetro encrypted messages remain compatible.

Numbered passwords

Recipe v1 uses Argon2id and HKDF-SHA256 to derive a 43-character base64url password. The recipe uses a fixed public salt for reproducibility, so a strong, unique source secret is essential. Identical inputs give identical passwords for everyone. A known generated password lets an attacker test secret guesses offline; finding the secret exposes all its password numbers.

A few important limits

There is no password recovery. Clearing removes values from the interface but cannot guarantee erasure from browser memory or clipboard history. Browser extensions, a compromised device, or a modified copy of this file can expose your secrets.
